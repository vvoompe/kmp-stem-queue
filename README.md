# KMP STEM-проєкт: імітаційна модель пункту видачі інтернет-замовлень

Дисципліна «Комп'ютерне моделювання процесів», тема № 10.

## Що це

Програмна імітація роботи пункту видачі інтернет-замовлень упродовж робочого дня.
Модель рахує, скільки клієнтів обслуговано, скільки втрачено і який простій працівників -
щоб визначити оптимальну кількість персоналу.

## Структура

- `src/input_stream.py` - генератори випадкових величин (потік клієнтів, час обслуговування)
- `src/sim_core.py` - ядро: моделює один день, веде чергу й обслуговування

## Як запустити

1. Встановити залежності:
   ```
   pip install -r requirements.txt
   ```
2. Запустити один день і подивитись показники:
   ```
   cd src
   python -c "from sim_core import simulate_day; print(simulate_day(2, 5, 3))"
   ```

`simulate_day(C, queue_limit, lam)`:
- `C` - кількість працівників;
- `queue_limit` - максимум місць у черзі;
- `lam` - середня кількість клієнтів за крок (15 хв).
